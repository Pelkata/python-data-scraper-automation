# Python Data Extraction & Logging Script

An automated Python tool designed to fetch live data from public endpoints, parse structured JSON, and append log records into a local CSV file.

## Features
- **Reliable Data Fetching:** Implements custom headers and error handling for HTTP requests.
- **Automated CSV Generation:** Dynamically builds header rows and appends timestamped records.
- **Production-Ready Structure:** Fully commented, PEP 8 compliant, and modular.
